GymRat is a modern fitness and gym management web application built with React that provides users with an interactive BMI and calorie calculator, workout exercise guides, fitness plans, reviews, FAQs, and a contact section. The project focuses on creating an engaging fitness experience through interactive components, responsive layouts, animated navigation, exercise visuals, and personalized calorie and macronutrient calculations.

## ✨ Features
- Interactive BMI calculator
- BMI category classification
- Daily calorie requirement calculation
- Weight-loss calorie recommendations
- Weight-gain calorie recommendations
- Protein, carbohydrate, and fat calculations
- Multiple calorie deficit and surplus levels
- Exercise library organized by muscle groups
- Chest, Back, Shoulder, Biceps, Triceps, Legs, and Abs exercise sections
- Exercises displayed for each muscle group
- Exercise images for visual guidance
- Interactive muscle-group navigation
- Active exercise category highlighting
- FAQ accordion section
- Gym membership/contact form
- Reviews section
- Fitness plans section
- Responsive design (available for desktop and mobile only)

## ⚠️ Problems Faced
- Managing different pages/components through the navigation system while keeping only the selected tab's content visible.
- Creating smooth transitions when switching between different navigation tabs without using third-party animation libraries.
- Creating the BMI and calorie calculation logic along with different weight-loss and weight-gain calorie levels.


##✅ Solutions Implemented
- Structured workout information into reusable JavaScript objects containing muscle groups, icons, exercise names, and exercise images.
- Used conditional rendering to display the currently selected muscle group's exercises.
- Used the Mifflin-St Jeor equation approach for calculating estimated daily calorie requirements.
- Calculated separate calorie targets for gradual, moderate, and aggressive weight loss/gain.
- Calculated protein, fat, and carbohydrate targets from body weight and calorie targets.
